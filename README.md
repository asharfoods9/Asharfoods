## Preview locally

Download/extract the repository and double-click `index.html`.

The site intentionally has no framework or external font dependency, so the layout and images work when opened directly from your computer.

## Publish with GitHub Pages

1. Create a GitHub repository, e.g. `ashars-foods`.
2. Upload all files in this folder to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide the live URL.

Typical URL:

`https://YOUR-USERNAME.github.io/ashars-foods/`

If a dedicated GitHub account uses the username `asharsfoods` and the repository is named `asharsfoods.github.io`, the URL can be:

`https://asharsfoods.github.io/`
